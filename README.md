# 여유로 (가칭) — 이동에 여유를

Pleos 기반 차량 서비스를 검토하기 위한 **한국어 인터랙티브 UI 프로토타입**입니다. 현재 구현은 HTML/CSS/ES modules이며, 실제 제품의 Kotlin 구현과 구분됩니다. 공식 인증·심사 적합성을 주장하지 않습니다.

## 실행과 검증

빌드나 외부 의존성 설치가 없습니다. `dist/`가 정적 사이트의 루트이자 읽을 수 있는 원본 소스입니다.

```sh
# 로컬 개발 예시 — ES module을 위해 file:// 대신 HTTP를 사용합니다.
python3 -m http.server 8000 --directory dist
# http://localhost:8000

npm test
```

관리형 Sites 환경에서는 임의 서버 대신 해당 환경의 `sites-preview`를 사용합니다. `.openai/`의 배포 식별자·호스팅 메타데이터는 GitHub 소스에서 제외합니다.

테스트는 Node 내장 `node:test`로 실행합니다. 시간 계산, 입력 검증, 경로 변경 확인, 동의/철회, 공유 종료, 주행 제한, 반복 조작, 창 전환 상태 보존, 화면 렌더링을 다룹니다. 실제 차량·SDK·휴대폰 연동 테스트가 아닙니다.

## 소스 구조

```text
dist/
  index.html                 앱 진입점과 메타데이터
  styles.css                 반응형·주간/야간·주행 가독성 스타일
  js/
    app.js                   부트스트랩, 화면 구성, 이벤트/키보드 연결
    data/demo.js             합성 목적지·주차 데이터, 공식 문서 링크
    domain/trip.js           순수 시간/도보/마감 여유 계산
    state/store.js           상태 저장소, 의도별 reducer, 안전 제한
    components/
      ui.js                  버튼, 아이콘, 시간 요약, 타임라인
      map.js                 비지리적 SVG 예시 지도
      drawer.js              설계 근거·SDK 상태 패널
    screens/
      trip.js                목적지 → 계획 → 이동 → 주차 완료
      companion.js           동의·공유, 동행자 준비·장소 제안
      phone.js               운전자 휴대폰 이어보기·복귀 리마인더
      places.js              예시 장소, 미확인/직접 확인 구분
      settings.js            선택 동의, 메모, 임시 편안함 미리보기
tests/
  trip.test.js               순수 시간·주차 계산 테스트
  store.test.js              상태 전이·안전·개인정보 테스트
  render.test.js             화면 조합·HTML 안전성 스모크 테스트
```

- **도메인**은 DOM, 브라우저, 차량 API를 모릅니다. 입력 상태로부터 시간을 계산하는 순수 함수입니다.
- **스토어**는 사용자 의도를 reducer에 전달합니다. `dispatch(action, payload)` 또는 액션 객체를 받습니다. 화면 함수는 읽기만 하고 상태를 직접 변경하지 않습니다.
- **화면**은 각 기능 영역을 소유하고, 공통 표현은 `components/`에 둡니다.
- **앱 진입점**은 이벤트 위임, 초점 복원, 드로어 키보드 제어와 브라우저 내 탐색만 연결합니다.
- **데이터**는 실제 API를 흉내 내는 고정 fixture입니다. API 성공을 가장하지 않으며, 플랫폼 어댑터가 아직 구현되어 있지 않습니다.
- **상태는 메모리에만** 있습니다. 서버·쿠키·localStorage를 쓰지 않으며 새로고침 시 초기화합니다.

## 체험 흐름

1. **이번 이동**에서 병원/집/카페 선택 → 약속 시간과 사람/차량 도착 기준 선택 → 주차 A/B 비교 → 출발.
2. **정차/주행** 데모 제어를 전환합니다. 주행 중에는 요약과 한 개의 상황 카드만 표시하며, 입력·상세 비교·설정은 제한됩니다. 데모 도구는 실제 차량 UI 밖에 있습니다.
3. **함께 이동** → 이번 이동 공유에 명시적으로 동의 → 공유 체험 → 상단의 **동행자** 화면에서 준비/미준비와 픽업 장소 제안.
4. 장소 제안은 운전자 검토 화면을 열 뿐, **변경 확인** 전에는 반영되지 않습니다. 취소하면 기존 계획을 유지합니다. 주차·경유 변경도 활성 이동에서는 같은 확인을 거칩니다.
5. **도착 체험** → 정차 상태에서 **주차 완료 확인** → **내 휴대폰**으로 마지막 도보와 복귀 리마인더를 확인합니다.
6. **장소 기록**에서 미확인 예시를 직접 확인한 예시로 바꿀 수 있습니다. **더보기**에서 기본 OFF인 학습 동의, 철회, 예시 수정 기록 삭제, 온도 미리보기/복원, 트렁크 모의 메모를 체험합니다.
7. 이동 취소·종료·픽업 완료·공유 철회 시 공유와 그 동의가 종료됩니다. 다음 이동으로 동의를 재사용하지 않습니다. 상단 **초기화**는 모든 데모 상태를 초기화합니다.

브라우저 뒤로/앞으로는 화면 선택만 복원하며 과거의 위치 공유 동의를 되살리지 않습니다. 계획 화면의 뒤로 가기는 시간/주차 선택을 보존합니다. 화면 크기·주야간·기기 전환도 진행 중 상태를 초기화하지 않습니다.

## 고정된 예시 시간의 의미

| 지점                         | 카페 경유 포함   |
| ---------------------------- | ---------------- |
| 출발                         | 13:30            |
| 카페 온유 도착               | 13:50            |
| 카페에서 차량으로 복귀 시작  | 14:10            |
| 차량 출발                    | 14:15            |
| 목적지 주차장에 차량 도착    | 14:45            |
| A 이용 시 사람이 목적지 도착 | 14:48 (도보 3분) |
| B 이용 시 사람이 목적지 도착 | 14:53 (도보 8분) |

15:00 약속을 기준으로 A는 12분, B는 7분 여유입니다. 차량 도착 기준은 15분 여유입니다. A 4,000원/B 2,000원은 **1시간의 합성 비교 요금**이며 두 곳 모두 빈자리 정보는 없습니다. 카페를 빼면 25분 일찍 도착하는 단순 예시입니다. 실제 경로·교통 모델이 아니므로 목적지 종류에 따른 실거리도 계산하지 않습니다. 지각하는 선택은 음수 여유를 숨기지 않고 ‘늦어요’로 표시합니다.

## 시뮬레이션의 경계

- 실제 지도, 위치, 차량 속도/기어, 내비게이션 호출, 트렁크 센서, 온도/시트 쓰기를 사용하지 않습니다.
- 마이크·브라우저 위치·OS 알림 권한을 요청하지 않습니다. 외부 API, 분석 SDK, 외부 폰트 요청이 없습니다. 공식 문서 링크를 열면 외부 사이트로 이동합니다.
- 공유는 같은 브라우저 안의 화면 교환입니다. 실제 수신자, 메시지, QR, 푸시, 계정/백엔드가 없습니다.
- 동행자 화면의 움직이는 차량은 **데모 애니메이션**입니다. 마지막 갱신 시각은 수동 모의 이벤트로 바뀌며 실제 위치의 신선도를 주장하지 않습니다. 주행 앱 화면에는 장식적인 자동 애니메이션이 없습니다.
- 주차 확정은 운전자의 명시적 확인입니다. 도착 이벤트만으로 ‘주차 완료’를 처리하지 않습니다.
- 임시 온도/복원은 **미리보기**이며 실제 설정을 바꾸거나 다음 시동에 자동 복원한다고 주장하지 않습니다.
- 장소 ‘확인’은 데모 입력을 표시하는 것이며 실제 방문/정보의 진위를 검증하지 않습니다.

### 기능 단위 이전 계획

- `domain/trip.js` → Kotlin 순수 use case/시간 값 객체. 도보와 차량 도착 시간을 계속 분리합니다.
- `state/store.js` → `ViewModel` + `StateFlow<UiState>`와 sealed user intents. 화면은 상태를 관찰하고 의도를 전달합니다.
- `screens/`·`components/` → Compose 화면/재사용 컴포넌트. 작은/확장 화면도 동일 상태를 공유합니다.
- NaviHelper → 선택한 경로만 요청하는 `NavigationGateway`; 성공은 비동기 콜백으로 확정합니다. 대안 경로 비교 지원은 별도 확인합니다.
- Vehicle State → 기능 지원 검사와 권한 이후 `VehicleStateGateway`. 주차를 기어 하나만으로 확정하지 않습니다.
- 현재 위치 → `LocationGateway`에서 NaviHelper 후보를 먼저 검증하되, 신선도/주기/배경 실행을 보장하지 않습니다.
- 온도·시트 → 권한이 확인될 때만 `ComfortGateway`. 미지원/거부/부분 실패/사용자 재설정 경로를 유지합니다.
- 음성·공유·푸시 → 각각 분리한 어댑터. 실제 서비스 승인, 개인정보 동의, 서버/폰 전달 확인 없이는 성공으로 표시하지 않습니다.

이 단계는 제품 사용 흐름을 빠르게 검토하기 위한 UI입니다. 공모전의 실행 가능한 차량 앱 제출물이나 APK를 대신하지 않습니다.
